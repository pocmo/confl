# Add attachments macro support to storage_to_markdown

Handle attachments macro that lists files on a page.

From storage-format-feature-gaps.md: Attachments list is useful to know what files are available.

Implementation:
- Handle <ac:structured-macro ac:name="attachments"> elements
- Option 1 (simple): Show placeholder [Page attachments]
- Option 2 (advanced): Make API call to fetch attachment list (configurable)
- Extract any parameters (old, upload, etc.)

Example storage format:
<ac:structured-macro ac:name="attachments">
  <ac:parameter ac:name="old">true</ac:parameter>
</ac:structured-macro>

Expected markdown:
[Page attachments]
or (if --resolve-macros enabled):
**Attachments:**
- document.pdf
- image.png

Priority: Medium - helpful to know files exist
Complexity: Moderate - placeholder simple, API integration moderate
Decision needed: Should we make API calls or just show placeholder?
