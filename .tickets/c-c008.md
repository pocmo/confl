# Add output format flags to page get command

Add --markdown, --json, --raw output flags to page get command per content-formats.md.

From content-rendering.md research:
- Default: Rich terminal rendering (storage → markdown → Rich)
- --markdown: Raw Markdown text (storage_to_markdown() only)
- --json: Full API response (json.dumps)
- --raw: Storage format as-is (body.storage.value)
- --plain: Plain text stripped of formatting (storage → markdown → strip)

Implementation:
1. Add mutually exclusive output format flags
2. Default: Rich Markdown rendering
3. --markdown: Print markdown text directly
4. --json: Print JSON response with pretty formatting
5. --raw: Print storage XML
6. --plain: Strip markdown formatting for plain text

Depends on: c-05e2 (page get implementation)

Acceptance:
- 'confl page get <id>' shows Rich rendering
- 'confl page get <id> --markdown' shows Markdown
- 'confl page get <id> --json' shows JSON response
- 'confl page get <id> --raw' shows storage XML
- 'confl page get <id> --plain' shows plain text
- Only one format flag allowed at a time
