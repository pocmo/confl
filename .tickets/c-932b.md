# Improve page link handling in storage_to_markdown

Convert Confluence page links (<ac:link><ri:page>) to readable markdown format.

From storage-format-feature-gaps.md: Page links are very common but may not be fully handled.

Implementation:
- Extract page title from <ac:link-body>
- Extract space key and content-title from <ri:page> attributes  
- Show as [Page Title] or construct URL if feasible
- Handle both inline and card appearance styles

Example storage format:
<ac:link ac:card-appearance="inline">
  <ri:page ri:space-key="PM" ri:content-title="Page Title" />
  <ac:link-body>Page Title</ac:link-body>
</ac:link>

Expected markdown: [Page Title] or [Page Title](URL)

Priority: High - internal links very common, affects navigation
Complexity: Moderate - needs XML parsing and text extraction
