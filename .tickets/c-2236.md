# Add support for <time> element rendering

Add support for rendering HTML <time> elements with datetime attributes. These are used in Confluence pages for date display in tables and other content.

Example from fixture: <time datetime="2026-02-15" local-id="..." />

Implementation:
- Add convert_time() handler in converter.py
- Extract datetime attribute
- Render as formatted date string (e.g., '2026-02-15')
- Handle both self-closing and container forms

Found in: tests/fixtures/pages/hub.xml and advanced-formatting.xml (Status Summary and Project Plan tables)

Impact: Date information currently lost when converting pages with time elements.
