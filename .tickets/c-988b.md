# Add GitHub Actions CI workflow

Create a GitHub Actions workflow that runs the same verification tools agents run locally.

## Tasks
- Create `.github/workflows/ci.yml`
- Run on push to main and pull requests
- Steps:
  1. Checkout code
  2. Setup Python 3.11
  3. Install uv
  4. Install dependencies: `uv sync`
  5. Run ruff format check: `uv run ruff format --check .`
  6. Run ruff lint: `uv run ruff check .`
  7. Run mypy: `uv run mypy src/`
  8. Run tests with coverage: `uv run pytest --cov`

## Acceptance Criteria
- Workflow runs successfully on push
- All checks (format, lint, type check, tests) must pass

## Notes
- Keep it simple — single job is fine
- Use uv for consistency with local development
