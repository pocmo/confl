# Add excerpt macro support to storage_to_markdown

Handle excerpt macro for reusable content blocks.

From storage-format-feature-gaps.md: Excerpt macro is common for page summaries.

Implementation:
- Handle <ac:structured-macro ac:name="excerpt"> elements
- Extract content from <ac:rich-text-body>
- Display with [Excerpt] label for clarity
- Preserve formatting within excerpt content

Example storage format:
<ac:structured-macro ac:name="excerpt">
  <ac:rich-text-body>
    <p>This is the excerpt content that can be reused elsewhere.</p>
  </ac:rich-text-body>
</ac:structured-macro>

Expected markdown:
[Excerpt]

This is the excerpt content that can be reused elsewhere.

Priority: Medium - common for summaries and reusable content
Complexity: Moderate - similar to existing macro handling with rich-text-body
