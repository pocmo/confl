Consider creating an examples/ directory with real-world workflow examples that are too detailed for getting-started.md. Potential examples:

- CI/CD integration (GitHub Actions workflow that updates release notes)

This would help users see practical applications beyond basic commands.

Before implementing, check if examples are better in:
1. Separate examples/ repo
