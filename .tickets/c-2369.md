# Enhancement: Add sorting options to confl space list

Add ability to sort spaces in 'confl space list' by different criteria.

## Problem
Spaces are returned in whatever order the API provides, which may not be useful for users trying to find specific spaces.

## Tasks
- Research what sorting options Confluence API supports for spaces
- Add --sort flag with options like:
  - name (alphabetical)
  - created (newest/oldest)
  - modified (most recently updated)
  - key (alphabetical by space key)
- Add --order flag: asc or desc
- Default to name ascending (most intuitive)
- Document in help text

## Acceptance Criteria
- `confl space list --sort name` sorts by space name
- `confl space list --sort modified --order desc` shows recently updated first
- Help text documents available sort options
- Default order is intuitive

## References
- src/confl/commands/space.py — space list command
- Confluence API docs for spaces endpoint sort options

## Notes
- Check if API supports sorting or if we need to sort client-side
- Consider what's most useful for users
- Similar to 'gh repo list --sort' pattern
