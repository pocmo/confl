# Improve page link handling in storage_to_markdown

Enhance converter to properly handle Confluence internal page links.

From content-rendering.md research:
- Storage format uses <ac:link> tags for internal links
- Example: <ac:link><ri:page ri:content-title="Page Title"/><ac:link-body>Link Text</ac:link-body></ac:link>
- Currently may not convert these properly

Implementation:
1. Add convert_ac_link() method to ConfluenceMarkdownConverter
2. Extract link text from <ac:link-body>
3. Extract page title from ri:content-title attribute
4. Convert to Markdown link: [Link Text](Page Title) or just show title
5. Handle space links (ri:space-key attribute)
6. Handle external links in ac:link tags

Testing:
- Add unit tests for various ac:link formats
- Test with page links, space links, external links
- Test with and without link-body

Acceptance:
- <ac:link> tags convert to Markdown links
- Link text preserved from link-body
- Page titles shown even without URL
- Doesn't crash on malformed links
