# Enhancement: Add confl space whoami command

Add command to show current user's personal space for better discoverability.

## Use Case
Users often don't know their personal space key (e.g., ~username, ~accountId). This command helps them find it quickly.

## Command
```bash
confl space whoami
```

Outputs:
- Personal space key
- Space name
- Space ID
- Link/URL
