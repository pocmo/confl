# Implement credentials storage module

Create a module for reading/writing credentials to ~/.config/confl/credentials.toml.

## Tasks
- Create `src/confl/credentials.py` module
- Implement functions:
  - `get_credentials_path()` — returns Path to credentials.toml
  - `load_credentials()` — reads and returns credentials (or None if not exists)
  - `save_credentials(site, email, token)` — writes credentials to file
  - `delete_credentials()` — removes credentials file
- Create `~/.config/confl/` directory if it doesn't exist
- Use TOML format:
  ```toml
  site = "mycompany.atlassian.net"
  email = "user@example.com"
  token = "api-token-here"
  ```
- Handle file permissions appropriately (credentials are sensitive)

## Acceptance Criteria
- Can save and load credentials round-trip
- Directory is created if missing
- Returns None/empty gracefully if no credentials file exists

## References
- docs/architecture/configuration.md — credentials location and format

## Notes
- Add `tomli` (read) and `tomli-w` (write) to dependencies, OR use built-in tomllib (Python 3.11+) for reading + simple write
