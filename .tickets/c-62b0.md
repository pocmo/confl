Discovery completed. Researched Python libraries for Markdown↔Storage conversion.

Key findings:
- Recommend md2cf (Mistune-based) for Markdown→Storage conversion
- Recommend markdownify (with custom Confluence renderer) for Storage→Markdown
- Both libraries well-maintained and suitable for our needs
- Core Markdown features fully supported (headings, lists, code, tables, links, images)
