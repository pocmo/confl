## Testing Tasks

### 1. Basic Operations
- Test `confl page get <page-id>` with various pages
- Test `confl page list --space <key>`
- Test `confl auth status`
- Verify authentication is working

### 2. Error Handling
- Test with invalid page IDs
- Test with non-existent spaces
- Test with pages you don't have access to

### 3. Output Quality
- Are error messages helpful or raw JSON dumps?
- Is content rendered nicely or ugly XML/HTML?
- Are tables/lists readable?

- Is --body-only flag useful?

### 4. Performance
- How fast are commands?
- Are there any timeouts or delays?
- Do large pages work well?

### 5. UX Issues
- What's confusing or awkward?
- What requires too many steps?
- What error messages are unclear?
- What would make the tool easier to use?

### 6. Edge Cases
- Personal spaces (starting with ~)
- Pages with complex formatting
- Pages with macros
- Pages with attachments
- Empty pages
- Very long pages
