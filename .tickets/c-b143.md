# Implement API client get_page method

Add get_page(page_id) method to ConfluenceClient that fetches a single page by ID using the Confluence REST API v2.

## Tasks
- Add get_page(page_id: str) method to ConfluenceClient class
- Use GET /wiki/api/v2/pages/{id} endpoint
- Include body-format=storage and body-format=atlas_doc_format in query params
- Return full API response
- Handle 404 (page not found) and 401 (unauthorized) errors appropriately
- Add type hints for return value

## Acceptance Criteria
- Method returns page data including id, title, body content
- Tests use pytest-httpx to mock API responses
- Error cases are handled with clear exceptions
