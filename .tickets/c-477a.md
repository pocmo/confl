# Implement auth login --token and auth logout commands

Add the auth command group with login --token and logout commands.

## Tasks
- Create `src/confl/commands/auth.py` (or add to cli.py)
- Add `confl auth` command group to CLI
- Implement `confl auth login --token`:
  - Requires `--site` flag (e.g., `mycompany.atlassian.net`)
  - Requires `--email` flag
  - Reads token from stdin (non-interactive, pipeable)
  - Stores credentials using credentials module
  - Example: `echo "$TOKEN" | confl auth login --token --site mycompany.atlassian.net --email user@example.com`
- Implement `confl auth logout`:
  - Deletes stored credentials
  - Succeeds silently if no credentials exist

## Acceptance Criteria
- `echo "token" | confl auth login --token --site X --email Y` stores credentials
- `confl auth logout` clears credentials
- Both commands provide clear success/error messages
