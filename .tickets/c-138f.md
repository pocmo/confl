# BUG/CLARIFY: confl space list --label doesn't find spaces by name

The 'confl space list --label' flag doesn't find spaces by the name shown in the table output.

## Bug Description
Running `confl space list --label <name>` doesn't find spaces by their name, neither:
- Full name matches (exact name from table)
- Partial name matches

This is confusing because the table shows a 'Name' column, so users expect --label to search by that name.

## Questions to Clarify
1. What is --label actually supposed to do?
   - Is 'label' a Confluence-specific concept (like tags/labels on spaces)?
   - Or is it supposed to filter by space name?
2. If it's for Confluence labels (not names), should it be renamed/documented better?
3. Should we add a --name flag for filtering by space name?
4. Is the implementation correct but just needs better documentation?

**2026-01-15T12:55:57Z**

RESOLVED: This is a documentation/UX clarity issue, not a bug.

The --label flag works correctly - it filters by Confluence space labels/categories (metadata tags assigned to spaces), not by space names.

What I did:
1. Updated help text to clarify: 'Filter by space label/category (Confluence metadata, not name)'
2. Added note in docstring directing users to 'confl space search <query>' for name-based search
3. Made it clear that labels are metadata tags, not names

The implementation is correct. The confusion was due to unclear help text. Users who want to search by space name should use 'confl space search <query>' instead.
