# Setup mypy for type checking

Add mypy for static type checking to catch bugs early.

## Tasks
- Add mypy to dev dependencies
- Configure mypy in pyproject.toml [tool.mypy]:
  - Set Python version (3.11)
  - Enable reasonable strictness (start moderate, not full strict)
  - Configure package paths (src layout)
- Fix any type errors in existing code (src/confl/cli.py)
- Verify mypy passes

## Suggested Configuration
```toml
[tool.mypy]
python_version = "3.11"
warn_return_any = true
warn_unused_ignores = true
disallow_untyped_defs = true
packages = ["confl"]
mypy_path = "src"
```
