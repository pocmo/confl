# Implement configuration loading

Implement the configuration system to load settings from environment variables.

## Tasks
- Create `src/confl/config.py` module
- Load configuration from environment variables:
  - `CONFL_SITE` — Confluence site (e.g., `mycompany.atlassian.net`)
  - `CONFL_TOKEN` — API token for authentication
  - `CONFL_EMAIL` — Email associated with API token
- Create a Config dataclass/model to hold settings
- Provide a `get_config()` function that returns the current config
- Raise clear error if required vars are missing (site + token + email for API calls)

## Acceptance Criteria
- `get_config()` returns config populated from env vars
- Missing required vars raise clear error with guidance
- Config values are validated (e.g., site looks like a hostname)
