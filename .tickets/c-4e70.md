# Implement 'task' subcommand for task tracking

Implement the 'task' CLI entity with commands: list, get, update. Tasks are action items in Confluence pages. Reference: docs/architecture/cli-subcommands.md Phase 3. Commands: confl task list (list tasks assigned to current user), confl task get <id> (get task details), confl task update <id> --status complete (mark complete/incomplete). Limited API but useful for teams tracking work in Confluence.
