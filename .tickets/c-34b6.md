# Add dependency version upper bounds

Add upper bounds to runtime dependencies to prevent breaking changes from major version updates.

Current:
- Dependencies use minimum version only: typer>=0.9.0
- No upper bounds means major version bumps auto-install

Proposed:
- Use semver upper bounds: typer>=0.9.0,<1.0.0
- Apply to all 5 runtime dependencies: typer, rich, httpx, tomli-w, mistune
- Dev dependencies can remain flexible

Benefits:
- Prevents breaking changes from surprise major version updates
- Tests will catch issues before updating
- More predictable behavior in production

Note: Not urgent since tests catch breaking changes. P3 priority.
