# Implement auth status command

Add command to show current authentication state.

## Tasks
- Implement `confl auth status`
- Check auth sources in precedence order:
  1. Environment variables (CONFL_SITE, CONFL_TOKEN, CONFL_EMAIL)
  2. Credentials file (~/.config/confl/credentials.toml)
- Display:
  - Auth source ("environment variables" or "credentials file" or "not authenticated")
  - Site
  - Email
  - Token (masked, e.g., "sk-****1234")
- Exit code 0 if authenticated, 1 if not

## Output Example
```
Authenticated via: environment variables
Site: mycompany.atlassian.net
Email: user@example.com
Token: ****abcd
```

## Acceptance Criteria
- Shows correct source when using env vars
- Shows correct source when using credentials file
- Shows clear message when not authenticated
- `--json` flag outputs machine-readable format
