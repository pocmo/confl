# Add user mention support to storage_to_markdown

Convert Confluence user mentions to @username format.

From storage-format-feature-gaps.md: User mentions are common in collaborative pages.

Implementation:
- Handle <ri:user> elements
- Extract username or account-id attribute
- Convert to @username format for readability
- If full name available, consider using that

Example storage format:
<ri:user ri:username="jsmith" />
or
<ri:user ri:account-id="abc123" ri:userkey="~jsmith" />

Expected markdown: @jsmith or @John Smith

Priority: Medium - common in collaborative content
Complexity: Simple - just extract attribute and format
