# Implement HTTP client for Confluence API

Create a base HTTP client configured for Confluence Cloud REST API v2.

## Tasks
- Create `src/confl/client.py` module
- Use httpx as the HTTP library (already a dependency)
- Configure client with:
  - Base URL: `https://{site}/wiki/api/v2`
  - Auth header: Basic auth with email:token
  - Appropriate headers (Accept: application/json, etc.)
- Create a `get_client()` function that returns configured httpx.Client
- Handle common API errors and convert to clear error messages
- Use exit codes per cli-design.md (0=success, 1=API error, 2=usage error)

## Acceptance Criteria
- `get_client()` returns httpx.Client ready for API calls
- Client uses config from `get_config()`
- API errors produce clear error messages to stderr

## References
- docs/architecture/cli-design.md — error handling, exit codes
- docs/architecture/design-principles.md — human-friendly output
- Confluence Cloud REST API v2: https://developer.atlassian.com/cloud/confluence/rest/v2/intro/

## Notes
- Keep it simple — synchronous client is fine for CLI
- Don't implement retry logic yet — add later if needed
