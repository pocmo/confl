# Fix GitHub Actions workflow - uv.lock not found in checkout

The GitHub Actions CI workflow is failing because uv.lock is not found after checkout.

## Bug Description
The workflow fails at the 'Install uv' step with:
```
Searching files using cache dependency glob: **/uv.lock
No matches found for glob
Error: No file matched to [**/uv.lock], make sure you have checked out the target repository
```

## Root Cause
The uv.lock file exists in the repository root, but it's not being found during the workflow run. Possible causes:
- Repository not checked out before the setup-uv step
- Checkout action missing or not completing successfully
- Working directory issue
- uv.lock not committed to git (though it should be)

## Tasks
- Review .github/workflows/ CI workflow file
- Ensure actions/checkout@v4 runs BEFORE astral-sh/setup-uv@v4
- Verify uv.lock is committed to the repository
- Add debug step to list files if needed
- Test that workflow runs successfully

## Acceptance Criteria
- GitHub Actions workflow runs without errors
- uv.lock is found and used for dependency caching
- All CI steps complete successfully
