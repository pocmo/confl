# Setup ruff for linting and formatting

Add ruff as the linter and formatter for consistent code style.

## Tasks
- Add ruff to dev dependencies
- Configure ruff in pyproject.toml:
  - Set target Python version (3.11)
  - Set line length (88 or 100)
  - Enable sensible rule sets (E, F, I for imports, UP for pyupgrade)
  - Configure src layout (src/confl)
- Run ruff format on existing code
- Run ruff check --fix on existing code
- Verify no lint errors remain

## Acceptance Criteria
- `uv run ruff format .` runs without changes needed
- `uv run ruff check .` passes with no errors

## Notes
- Ruff replaces black, isort, flake8, and more
- Agents should run `uv run ruff format . && uv run ruff check --fix .` before commits
