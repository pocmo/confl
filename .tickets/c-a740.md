# Add task list support to storage_to_markdown

Convert Confluence task lists to markdown checkboxes.

From storage-format-feature-gaps.md: Task lists are common in project management pages.

Implementation:
- Handle <ac:task-list> and <ac:task> elements
- Convert to markdown checkbox syntax: - [ ] (incomplete) or - [x] (complete)
- Extract task text and completion status
- Support nested task lists if present

Example storage format:
<ac:task-list>
  <ac:task>
    <ac:task-status>incomplete</ac:task-status>
    <ac:task-body>Task description</ac:task-body>
  </ac:task>
</ac:task-list>

Expected markdown:
- [ ] Task description
- [x] Completed task

Priority: Medium - common in project pages
Complexity: Moderate - needs custom element handling
