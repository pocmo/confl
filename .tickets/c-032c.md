# Add Jira macro support to storage_to_markdown

Extract and display Jira issue keys from Jira macro.

From storage-format-feature-gaps.md: Jira macro is very common in development team pages.

Implementation:
- Handle <ac:structured-macro ac:name="jira"> elements
- Extract issue keys from parameters (may be JQL query or explicit list)
- Display as readable list: [Jira: PROJ-123, PROJ-124]
- Handle both single issues and JQL queries

Example storage format:
<ac:structured-macro ac:name="jira">
  <ac:parameter ac:name="key">PROJ-123</ac:parameter>
</ac:structured-macro>

or with JQL:
<ac:parameter ac:name="jqlQuery">project = PROJ AND status = Open</ac:parameter>

Expected markdown:
[Jira: PROJ-123]
or
[Jira query: project = PROJ AND status = Open]

Priority: High for dev teams - very common integration
Complexity: Moderate - needs parameter extraction and formatting
