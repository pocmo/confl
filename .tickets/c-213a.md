# Refactor to context object pattern to break circular import

Break circular dependency between cli.py and client.py by introducing a context object.

Current Issue:
- client.py imports from cli.py (get_profile, is_debug, is_verbose) via late imports
- This creates coupling where client layer depends on CLI layer

Solution:
Create src/confl/context.py with ExecutionContext dataclass:
- profile: str | None
- verbose: bool
- debug: bool

Benefits:
- Breaks circular import (no more late imports)
- Makes context explicit and testable
- Improves separation of concerns
- Easier to pass context to functions
